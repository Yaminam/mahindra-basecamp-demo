# Mahindra Basecamp: concept demo

Clickable concept for a Mahindra accessories, merchandise and trails store, prepared as pitch material.
**Not an official Mahindra website.** Products, prices, dealers and dates are illustrative.

## Run locally

```bash
npm install
npm run dev      # development
npm run build    # single-file build in dist/ (opens from disk)
```

## Stack

Vite, React 19, Tailwind CSS 4, Motion, three.js (React Three Fiber), GSAP, Lenis.
